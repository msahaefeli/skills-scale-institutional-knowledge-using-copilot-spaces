# OctoAcme — Role Ownership & Handoff Checklist

## Purpose
Provide a lightweight, reusable guide to confirm ownership, collaboration points, and handoffs before delivery starts.

## When to use
- During project kickoff
- Before each major milestone or release planning cycle

## Core responsibility matrix (lightweight)
Use this matrix to name one accountable owner and supporting collaborators for each activity.

| Activity | Accountable role | Key collaborators |
| --- | --- | --- |
| Define problem, outcomes, and success metrics | Product Manager | Stakeholders, SME, UX Designer |
| Build project plan, schedule, and risk register | Project Manager | Scrum Master, Product Manager |
| Prepare design flows and UX acceptance notes | UX Designer | Product Manager, Developers, QA/Testing |
| Finalize sprint scope and execution cadence | Scrum Master | Project Manager, Product Manager, Developers |
| Implement features and technical validation | Developers | QA/Testing, UX Designer, SME |
| Validate acceptance and quality readiness | QA/Testing | Developers, Product Manager, SME |
| Coordinate release readiness and communications | Release Manager | DevOps Engineer, QA/Testing, Project Manager |
| Execute deployment and operational verification | DevOps Engineer | Release Manager, Developers |
| Approve business/domain readiness decisions | Stakeholders / SME (as needed) | Product Manager, Project Manager |

## Project kickoff ownership checklist
- [ ] Project Manager and Product Manager are named, with backups identified.
- [ ] Scrum Master ownership is assigned for team cadence and blocker escalation.
- [ ] UX Designer involvement is confirmed for discovery and design handoff timing.
- [ ] SME involvement is defined for domain review points and decision gates.
- [ ] Release Manager and DevOps Engineer ownership is assigned for release/deployment readiness.
- [ ] QA/Testing owner is assigned for acceptance and quality sign-off.
- [ ] Escalation path is documented (Team -> PM -> Product Lead -> Sponsor).

## Handoff checklist by phase
### Discovery -> Planning
- [ ] Product Manager provides prioritized problem statements and success metrics.
- [ ] UX Designer provides initial flows/prototypes and unresolved UX risks.
- [ ] SME provides domain constraints and critical edge cases.

### Planning -> Execution
- [ ] Project Manager confirms milestones, dependencies, and owners in the project board.
- [ ] Scrum Master confirms sprint goals, capacity, and known blockers.
- [ ] Developers and QA/Testing confirm acceptance criteria are testable.

### Execution -> Release
- [ ] Developers confirm implementation complete and documentation updated.
- [ ] QA/Testing confirms sign-off status and open-risk summary.
- [ ] Release Manager confirms release notes, rollout plan, and rollback plan.
- [ ] DevOps Engineer confirms environment and pipeline readiness.

### Release -> Post-release
- [ ] DevOps Engineer confirms deployment verification and monitoring status.
- [ ] Release Manager communicates release outcome and known issues.
- [ ] Product Manager, Project Manager, and SME confirm follow-up actions and ownership.

## Suggested cadence for maintaining ownership clarity
- Reconfirm role ownership at kickoff and whenever team composition changes.
- Review handoff readiness in weekly delivery syncs.
- Capture ownership updates in project documentation before each release.
